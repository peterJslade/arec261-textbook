11  Graphing in Excel

Excel creates a chart from a range of cells. The important part happens before the chart menu opens: decide what one row represents, calculate the values the chart needs, and arrange them in the order the reader should see.

The examples use sixty hypothetical canola fields. They build a bar chart of mean yield by region, a line chart of mean yield by year and a scatter plot of field size against yield.

Learning Objectives

By the end of this chapter you should be able to:

  1. Arrange a worksheet table for a bar, line or scatter chart.
  2. Create a chart from a selected range.
  3. Add a descriptive title and state the units.
  4. Change an axis without making the comparison misleading.
  5. Decide when a legend, data labels or direct labels are needed.
  6. Copy a chart into a document or save it as an image.

11.1 Start With the Table

A chart reads the cells you select. If those cells contain raw field records when the question concerns regional averages, summarize first. A chart cannot decide which calculation the question requires.

The bar chart has three bars, so its source table has three rows: one region and one mean per row. The line chart has one row per year. The scatter plot uses the raw observations because each field is meant to appear as one point.

Region Mean yield (bu/ac) Fields with yield
Central 47.6 19
North 47.3 19
South 42.7 19

Three of the sixty fields have no recorded yield. AVERAGEIF omits those blanks, and a scatter plot draws no point for them, so these charts represent 57 fields. Each regional mean summarizes fields whose yields vary substantially; the 0.3 bu/ac difference between Central and North should not be treated as a meaningful ranking without examining that variation.

Use =AVERAGEIF(Data[region],A2,Data[yield_bu_acre]) when the raw data is an Excel Table named Data. A structured reference expands as rows are added. If a summary cell shows #DIV/0! or the chart is blank, check whether the supposed numeric source column was imported as text (Section 9.3.3).

11.2 Create a Chart

Select the table, including its headers, and use the Insert tab to choose a chart type. Excel normally uses a text first column as categories, but it may treat a numeric first column—such as Year—as another series. Use Chart Design > Select Data, remove Year from the series list, and set the Year cells as the Horizontal (Category) Axis Labels.

For the three charts in the workbook:

  • The bar chart selects region and mean yield, then uses a column chart for vertical bars or a bar chart for horizontal bars.
  • The line chart selects year and mean yield, then uses a line chart with markers.
  • The scatter plot selects acres and yield, then uses an XY scatter chart. A line chart is not a substitute here because field size is a measured number rather than an ordered label.

The chart remains linked to its cells. Editing the source values changes the chart; pasting new values outside a plain selected range may not. An Excel Table expands when rows are added and is usually a better source for a chart that will receive new data.

The two-year line chart is useful for learning the mechanics, but two values are more honestly reported as a sentence: mean yield was 45.8 bu/ac in 2024 and 46.0 bu/ac in 2025. A substantive trend chart needs more years.

11.3 Titles, Axes and Legends

Use Chart Design > Add Chart Element to add or remove titles, axis labels, legends and data labels. A useful chart title describes the comparison and includes the unit when the axes do not make it obvious: Average field yield by region (bu/ac).

Bar charts normally need a zero baseline. Select the value axis, right-click Format Axis, and under Axis Options > Bounds set Minimum to 0. Mac users use the Chart Design tab for chart elements; the + button beside a selected chart is Windows-only. A line chart may use a narrower vertical range because its values are positions connected through time rather than lengths measured from a baseline (General Principles, Section 10.1), but the chosen bounds should be reported and checked.

Excel draws bars in the order of the source rows. Sort the summary table to change their order; for a horizontal bar chart, use Format Axis > Categories in reverse order to place the first row at the top.

A legend is needed when colour or shape identifies several series. A one-series chart does not need a legend that says Mean yield; the title and axis already say that. For a few lines, direct labels can be clearer than a legend.

Data labels are useful when the exact values matter and there are only a few marks. Labelling every point in a scatter plot usually hides the pattern.

11.4 Formatting the Chart

Excel’s default chart is a starting point. Remove borders, gridlines or colours that do not help the comparison. Keep light horizontal gridlines when readers need to estimate values from the axis. Avoid three-dimensional effects, shadows and patterned fills.

Colour can identify a group or highlight one result. It does not need to change for every bar. Keep the same colour meaning across charts in the same report.

To change the size or typeface of an element, click the element itself before formatting it. This avoids changing the whole chart when only the axis labels need attention.

11.5 Moving a Chart Into a Report

Copying a chart from Excel into Word or PowerPoint gives several paste options. The Picture option—or Paste Special > Picture (PNG)—fixes its appearance and prevents later workbook edits from changing the document. A linked chart updates from the workbook but can break when the files are moved or sent to someone else.

Desktop Excel can also use Save as Picture from a chart’s right-click menu; Excel for the web cannot. PNG works for web pages and slides. Use enough width that the labels remain readable at the size used in the report.

Before handing it over, check the source range, category order, axis minimum, labels and units. Compare one plotted value with its source cell.
