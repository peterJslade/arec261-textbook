11  Graphing in Excel

The examples in this chapter use canola_trial.csv, the same simulated variety trial used in Module 2. The file has 120 fields, with fertilizer rate, growing-season rainfall, variety and yield recorded for each field.

The main example compares mean yield for InVigor, Clearfield and DEKALB. The R chapter answers the same questions with the same data.

Learning Objectives

By the end of this chapter you should be able to:

  1. Build a chart from a worksheet summary table.
  2. Check and correct the categories and series used by a chart.
  3. Change the chart title, axis titles, bounds and tick spacing.
  4. Decide whether a legend or data labels help the reader.
  5. Create a scatter plot and histogram from numeric data.
  6. Format and export a chart without adding unnecessary decoration.

11.1 The worked workbook

The workbook contains the raw canola data and a finished bar chart, scatter plot and histogram. Open the Bar chart sheet first. The nine numbered steps beside the chart are meant to be followed in Excel.

TipWorkbook: graphing examples in Excel

Open the view-only workbook online or download a copy.

11.2 Start with the chart-driving table

The raw file has one row per field, but the question asks for one mean per variety. The chart therefore reads a three-row summary table rather than all 120 raw rows.

The Bar chart sheet uses AVERAGEIF to calculate mean yield and COUNTIF to report how many fields contributed. InVigor averages 54.5 bu/ac across 42 fields, Clearfield 53.5 across 39 fields and DEKALB 52.2 across 39 fields.

The formula column is present for inspection but is not part of the chart. A chart should select only the category labels and the values that determine the marks.

11.3 Create the bar chart

Select cells A4:B7 on the Bar chart sheet, including the two headers. Use Insert > Column or Bar Chart > Clustered Column.

Excel calls vertical bars a column chart and horizontal bars a bar chart. Both compare categories by length. The workbook uses vertical bars, which fit the three short variety names. A horizontal chart is often better when category labels are long.

Selecting columns C and D as well would make Excel treat field counts or formula text as additional chart data. If that happens, use Chart Design > Select Data and remove the extra series, or delete the chart and select only A4:B7 again.

11.4 Check the source data

With the chart selected, open Chart Design > Select Data. The Legend Entries (Series) list should contain one series named Mean yield (bu/ac). The Horizontal (Category) Axis Labels should be the three variety cells.

If the varieties appear in the legend and the means appear along the horizontal axis, click Switch Row/Column. This is a correction for chart orientation, not a different calculation.

The chart remains linked to the summary cells. Editing a mean changes the corresponding bar. Sorting the summary rows changes the order of the bars.

11.5 Change the title

Click the default chart title and type Average canola yield by variety. If the title is missing, use Chart Design > Add Chart Element > Chart Title > Above Chart.

A title should name the comparison. The unit can appear in the title or the value-axis title, but it does not need to appear twice. This chart puts the unit on the vertical axis.

To change the title’s typeface or size, click the title itself before using the Home tab or the Format Chart Title pane. Clicking the chart background selects the chart area instead and changes a different element.

11.6 Add and alter the axes

Use Chart Design > Add Chart Element > Axis Titles > Primary Vertical and type Mean yield (bu/ac). The variety names already identify the horizontal categories, so an additional horizontal title would add little.

Right-click the vertical-axis numbers and choose Format Axis. Under Axis Options, set Minimum to 0, Maximum to 60 and Major unit to 10.

The minimum matters because bar length is measured from the baseline. Starting the axis near 50 would make the 2.3 bu/ac difference between InVigor and DEKALB look much larger than it is. A line or scatter plot can use a narrower scale because values are encoded by position rather than bar length.

Excel places categories in the order of the source rows. Sort the summary table to change that order. For a horizontal bar chart, Format Axis > Categories in reverse order places the first source row at the top.

11.7 Legends, labels and colour

This chart has one series, so its legend repeats information already supplied by the axis and title. Remove it with Chart Design > Add Chart Element > Legend > None.

Exact values are useful when there are only three bars. Use Chart Design > Add Chart Element > Data Labels > Outside End, then open Format Data Labels > Number and show one decimal place. Data labels are less useful when a chart has many bars.

Click one bar once to select the whole series, then choose one fill colour. Clicking the same bar a second time selects only that bar, which is useful when one category needs deliberate emphasis. Different colours for all three bars would suggest meanings that are not present in the data.

Light horizontal gridlines help readers estimate values from the scale. Remove heavy borders, shadows, gradients and three-dimensional effects.

11.8 Create the scatter plot

The Scatter plot sheet compares growing-season rainfall with yield. An XY scatter chart is needed because both variables are measured numbers.

On the Canola data sheet, rainfall is in column C and yield is in column E. Select the rainfall values, then hold Ctrl on Windows or Command on macOS while selecting the yield values. Use Insert > Scatter > Scatter with only Markers.

Open Chart Design > Select Data, edit the series and confirm that the X values are C2:C121 and the Y values are E2:E121. Three fields have missing rainfall, so the chart contains 117 points. The correlation is about 0.65 and the point cloud has a visible upward slope.

Add the title Canola yield by growing-season rainfall, label the horizontal axis Growing-season rainfall (mm) and label the vertical axis Yield (bu/ac). Do not connect the fields with lines because the rows do not form a sequence.

11.9 Create the histogram

Select the yield values in E1:E121 on the Canola data sheet and use Insert > Insert Statistic Chart > Histogram. Right-click the horizontal axis, choose Format Axis and set Bin width to 4.

The workbook also shows the bin counts in cells. The nine counts add to 120 and cover yields from 39.3 to 70.4 bu/ac. Changing the bin width changes the visible shape, so the chosen width belongs in the chart title or surrounding explanation.

Use Canola trial yields (4 bu/ac bins) as the title. The horizontal axis is yield in bu/ac and the vertical axis is the number of fields.

11.10 Resize, copy and export

Drag a corner handle to resize a selected chart without distorting it. Leave enough room for the title, labels and tick marks, and check the chart at the size it will occupy in the report.

Copying a chart into Word or PowerPoint provides several paste options. Picture or Paste Special > Picture (PNG) fixes its appearance. A linked chart can update from Excel but can break when the workbook and document are moved or shared separately.

Desktop Excel also provides Save as Picture from a chart’s right-click menu. Before exporting, compare one plotted value with its source cell and check the title, source range, axis bounds, labels, units and number of observations.
