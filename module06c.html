19  Making and Interpreting Maps

A map made with geom_sf() is a ggplot. Everything from Chapter 12 carries over – aesthetics, scales, facets, labels – and the decisions that make a chart honest make a map honest too.

19.1 A first map

Chapter 18 saved the RM boundaries with 2023 canola yields attached. Read the file back and put the yield on the map as fill:

# Load the spatial package
library(sf)

# The boundaries-plus-yields layer saved in the last chapter
rm_canola <- st_read("output/rm_canola_2023.gpkg", quiet = TRUE)

# Fill each polygon by its yield
ggplot(rm_canola) +
  geom_sf(aes(fill = Canola), colour = "grey40", linewidth = 0.05) +
  scale_fill_viridis_c(na.value = "grey85") +
  theme_void() +
  labs(fill = "bu/ac")

A map coloured by a value is a choropleth. Two of its choices matter more than the rest. The colour scale is the first: scale_fill_viridis_c() runs from dark to light in even perceptual steps, so twice the difference in yield looks like twice the difference in colour. The second is the grey polygons. Those RMs have NA for canola – no reported yield – which is not the same as a yield of zero, and na.value = "grey85" keeps the two from sharing a colour. A missing area painted the same as a low value is a quiet lie.

19.2 Categorical scales

Sometimes classes read better than a continuous ramp. Make the classes with case_when(), then map the new column:

# Three yield classes, with the cutoffs visible in the code
rm_canola <- rm_canola |>
  mutate(yield_class = case_when(
    Canola < 30 ~ "Under 30",
    Canola <= 40 ~ "30 to 40",
    Canola > 40 ~ "Over 40"
  ) |>
    factor(levels = c("Under 30", "30 to 40", "Over 40")))

# Map the classes
ggplot(rm_canola) +
  geom_sf(aes(fill = yield_class), colour = "grey40", linewidth = 0.05) +
  scale_fill_brewer(palette = "YlGn", na.value = "grey85") +
  theme_void() +
  labs(fill = "bu/ac")

Classes trade detail for readability, and the cutoffs are decisions: moving an edge from 30 to 35 redraws the map without changing a single yield. Put the cutoffs in the legend or the caption so a reader can see them.

19.3 Comparing years

A comparison across maps is honest only when the maps share a scale. Join two years of canola instead of one, and let facet_wrap() draw both – the shared fill scale comes free:

# Canola for the two years, one row per RM per year
canola_years <- read_csv("data/rm_yields_1990plus.csv", show_col_types = FALSE) |>
  filter(Year %in% c(2021, 2023)) |>
  select(Year, RM, Canola)

# The boundaries
rms <- st_read("data/sask_rms.geojson", quiet = TRUE) |>
  mutate(RMNO = as.numeric(RMNO))

# Join each year separately, so every RM appears in both panels
rm_two_years <- bind_rows(
  left_join(rms, filter(canola_years, Year == 2021), by = c("RMNO" = "RM")) |>
    mutate(Year = 2021),   # keep the year on the RMs that had no row
  left_join(rms, filter(canola_years, Year == 2023), by = c("RMNO" = "RM")) |>
    mutate(Year = 2023)
)

# One map per year, one scale for both
ggplot(rm_two_years) +
  geom_sf(aes(fill = Canola), colour = "grey40", linewidth = 0.05) +
  scale_fill_viridis_c(na.value = "grey85") +
  facet_wrap(~ Year) +
  theme_void() +
  labs(fill = "bu/ac")

The 2021 drought is the whole story of this figure, and it is only visible because both panels use one scale. Scaled separately, each map would use its full colour range and the two years would look alike.

19.4 Adding a basemap

At the scale of an RM or a field, a map floating on white loses its bearings. annotation_map_tile() from the ggspatial package draws web map tiles under the other layers, the way an online map does:

# Load the package for basemaps and scale bars
library(ggspatial)

# The RM to show
wood_creek <- rms |>
  filter(RMNO == 281)

# Tiles underneath, the boundary on top, a scale bar in the corner
ggplot(wood_creek) +
  annotation_map_tile(type = "osm", zoom = 10, progress = "none") +
  geom_sf(fill = NA, colour = "#4A7C59", linewidth = 0.9) +
  annotation_scale(location = "br") +
  theme_void()

The tiles come from OpenStreetMap, which needs no account. Commercial tile providers – Mapbox, Esri, Google – plug into the same layer once you have a key from them, and imagery basemaps work well under field-level data in Module 7. The scale bar answers the question every zoomed-in map raises, how far is that, and annotation_scale() computes it from the CRS.

19.5 Finishing a map

A finished map states what it shows, in what units, from what source. labs() does all three:

ggplot(rm_canola) +
  geom_sf(aes(fill = Canola), colour = "grey40", linewidth = 0.05) +
  scale_fill_viridis_c(na.value = "grey85") +
  theme_void() +
  labs(
    title = "Canola yield by rural municipality, 2023",
    fill = "bu/ac",
    caption = "Grey: no reported canola. Source: Saskatchewan Ministry of Agriculture RM yields."
  )

The same habits that mislead in a chart mislead on a map: a colour scale that starts partway up the data, class breaks chosen to make a pattern appear, a comparison across panels with different scales, missing areas coloured like data. None of them require bad intent, only inattention, and each one is caught by asking what a reader would conclude from the colours alone.
