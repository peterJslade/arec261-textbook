14  GitHub Copilot

GitHub Copilot works inside Positron. It can complete code while you type and provide a model for Posit Assistant chat, so the assistant can work with the script and project already open in the editor.

The useful part is the context. Copilot can see more of the file than a question pasted into a separate browser window. It still does not know what a dataset contains unless the data or its structure is included in that context.

Learning Objectives

By the end of this chapter you should be able to:

  1. Connect a GitHub Copilot account to Positron.
  2. Use inline completions and Posit Assistant chat for different tasks.
  3. Give the assistant enough information about a dataset to avoid guessing.
  4. Decide whether to accept, revise or reject suggested code.
  5. Check AI-assisted code before it becomes part of an analysis.

14.1 Getting Access

GitHub offers a limited Copilot Free plan to individual developers. Verified students can also be eligible for Copilot Student, which includes additional use without a paid subscription.

To apply for the student benefit:

  1. Create a personal account at github.com if you do not have one.
  2. Open your GitHub Education benefits and start a student application.
  3. Add and verify your @usask.ca address if GitHub asks for an academic email.
  4. Supply current proof of enrolment, such as a student card with an enrolment date, a class schedule, a transcript or an enrolment letter.
  5. After verification, return to the benefits page and activate the Copilot benefit. Education approval and Copilot activation are separate steps.
NoteCurrent access note

GitHub’s documentation says that new sign-ups for student and several paid Copilot plans have been temporarily paused since April 20, 2026. Existing student access continues, and Copilot Free remains available. Do not enter payment information for this course. Use the free plan while the pause is in place and check GitHub’s student access page for the current status.

Apply early. Verification can take several days, and the account may not be ready on the night an assignment is due.

14.2 Connecting Copilot to Positron

Recent versions of Positron include AI support directly. You do not need to install the GitHub Copilot extension from the Extensions pane.

  1. Update Positron before beginning.
  2. Open the Command Palette with Cmd+Shift+P on macOS or Ctrl+Shift+P on Windows.
  3. Run Authentication: Configure Language Model Providers.
  4. Select GitHub Copilot and sign in through the browser window that opens.
  5. Return to Positron and open Posit Assistant chat. Copilot should appear as an available provider.

Copilot’s grey inline completions become available after the same sign-in. If chat or completions do not appear, restart Positron. If the account was connected in an older Positron release, sign out of GitHub from the Accounts menu and sign in again.

The command AI: Create Diagnostic Report lists the active providers and AI settings without exposing the content of your prompts. It is the quickest check when Positron appears connected but produces no suggestions.

14.3 Two Ways to Use It

Inline completions

Inline completions appear as grey text while you type. Press Tab to accept a suggestion, Esc to dismiss it or keep typing to replace it.

A comment can provide a short instruction:

# Read the yield data and count rows by crop

Inline completion is useful for predictable syntax, repeated arguments and the next line of a pattern already present in the script. It is a poor place to ask for an explanation because the result arrives as code rather than a discussion.

Posit Assistant chat

Chat is useful for questions: why an error occurred, what a line does, how to reorganize a plot or what checks belong after a join. Select the relevant code or file before asking so the assistant receives the right context.

Posit Assistant is the default chat interface in Positron. GitHub Copilot can supply its language model after you connect the provider. This distinction matters when following documentation: Copilot is the account and model provider; Posit Assistant is the chat interface you see in Positron.

14.4 Show the Shape of the Data

Copilot cannot infer a file’s columns from its filename. If it has not seen sask_variety_yields.csv, code using df$yield is a guess.

Run glimpse(d), str(d) or head(d) and give the assistant the relevant output. A short comment above the request is often enough:

# d has columns: Risk_Zone, Crop, Variety, Year, Acres, Yield
# Crop includes "Barley", "Canola/Rapeseed", and "Wheat - Hard Red Spring"
# Acres and Yield contain missing values
#
# Compute mean 2025 yield by crop, weighted by acres

This supplies the column names, category spelling, missing-value problem and intended calculation. Without those details, the assistant has to invent them.

Context also has a privacy cost. A file included in an AI request leaves your machine. Public course data is suitable; confidential farm, employee, client or research data may not be. Follow the data owner’s rules and the restrictions in Section 13.8.

14.5 Accepting and Rejecting

Accept code when you can explain what it does and can name the check that would reveal an error.

  • Usually safe to accept after reading: syntax you recognize, plotting boilerplate and repetitive argument lists.
  • Read and test carefully: joins, filters, grouped summaries, missing-value handling and any code that changes the number of rows.
  • Stop and investigate: unfamiliar functions or packages, an unexpectedly long solution or code whose result you cannot predict.

Rejecting a suggestion costs almost nothing. Accepting code you do not understand leaves you responsible for a calculation you cannot defend or repair.

14.6 Checking the Work

Use the same checks after every AI-assisted change:

  1. Read every line and identify which data it uses.
  2. Count rows before and after a filter, join or grouped operation.
  3. Test the code on a small case whose answer is known.
  4. Recalculate one result another way.
  5. Inspect the final table or chart against the question that was asked.

The assistant can help write a check. It cannot replace the independent evidence supplied by that check.
