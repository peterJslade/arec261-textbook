12  Graphing in R

The Excel chapter built four charts from worksheet ranges. In R we describe the same charts in code: the data, the variables assigned to visual properties and the marks to draw. The ggplot2 package turns that description into a figure.

The examples use field_yields.csv and rm_yields_2015_2024.csv, the same files used in the Excel workbook. The field data are simulated; the RM yield series comes from the Saskatchewan Agriculture provincial dashboard.

# Load the tidyverse
suppressPackageStartupMessages(library(tidyverse))

# Read the simulated field data
yields <- read_csv(
  "practice/data/field_yields.csv",
  show_col_types = FALSE
)

# Read the published RM yield data
rm_yields <- read_csv(
  "practice/data/rm_yields_2015_2024.csv",
  show_col_types = FALSE
)

# Calculate one regional mean per row
region_means <- yields |>
  group_by(region) |>
  summarise(
    mean_yield = mean(yield_bu_acre, na.rm = TRUE),
    fields = sum(!is.na(yield_bu_acre)),
    .groups = "drop"
  )

# Calculate one annual mean per row
annual_mean <- rm_yields |>
  group_by(Year) |>
  summarise(
    mean_yield = mean(Canola, na.rm = TRUE),
    .groups = "drop"
  ) |>
  rename(year = Year)

# Inspect both chart-driving summaries
region_means

Learning Objectives

By the end of this chapter you should be able to:

  1. Build a plot with ggplot(), aes() and a geom.
  2. Reproduce a bar, line, scatter and histogram chart from the Excel examples.
  3. Distinguish mapping an aesthetic to a variable from setting it to a constant.
  4. Add titles, axis labels, direct labels and annotations.
  5. Add a fitted pattern and divide a plot into facets.
  6. Save a plot with stated dimensions and resolution.

12.1 The grammar of graphics

ggplot2 follows the grammar of graphics. A plot is assembled from a few parts:

  • Data: the data frame to plot.
  • Aesthetic mappings: columns assigned to position, colour, size or shape.
  • Geometries: points, lines, bars, boxes and other marks.
  • Scales: the rules connecting data values to axis positions or colours.
  • Facets: separate panels for groups.

Some geoms also calculate a statistic. A histogram bins values before drawing bars, and a smooth fits a line or curve before drawing it.

Layers are joined with +. A pipe passes a data object into a function; the + adds another layer to a ggplot object.

12.2 Compare regional means with bars

The Excel chart used a three-row summary calculated with AVERAGEIF. The region_means data frame performs the same job in R. geom_col() draws values that have already been calculated.

# Put the highest mean first
region_means |>
  mutate(region = fct_reorder(region, mean_yield, .desc = TRUE)) |>
  ggplot(aes(x = region, y = mean_yield)) +
  # Draw the calculated means as bars
  geom_col(width = 0.7, fill = "#3F6F52") +
  # Keep a zero baseline for bar length
  scale_y_continuous(
    limits = c(0, 55),
    expand = expansion(mult = c(0, 0.04))
  ) +
  # State the variables and unit
  labs(
    x = NULL,
    y = "Mean yield (bu/ac)"
  ) +
  # Remove unnecessary decoration
  theme_minimal(base_size = 11)

Central and North differ by 0.3 bu/ac. The bar chart shows the difference, but it does not show the variation among the nineteen recorded fields behind each mean.

12.3 Show change through time with a line

The annual summary contains one mean for each year from 2015 to 2024. geom_line() connects those values in chronological order and geom_point() shows the observed annual means.

# Start with one row per year
ggplot(annual_mean, aes(x = year, y = mean_yield)) +
  # Connect the years in time order
  geom_line(colour = "#2878A5", linewidth = 0.7) +
  # Mark each annual mean
  geom_point(colour = "#2878A5", size = 2) +
  # Show each integer year
  scale_x_continuous(breaks = 2015:2024) +
  # Use the same displayed range as the Excel example
  scale_y_continuous(limits = c(15, 45)) +
  # State the unit
  labs(
    x = NULL,
    y = "Mean yield (bu/ac)"
  ) +
  # Use a restrained theme
  theme_minimal(base_size = 11)

The lowest annual mean is 21.9 bu/ac in 2021. As in Excel, blank RM yields are omitted from each annual mean rather than treated as zero.

12.4 Compare two numeric variables with points

A scatter plot assigns one numeric column to each position. Rows missing either value do not produce a point.

# Map field size and yield to position
ggplot(yields, aes(x = acres, y = yield_bu_acre)) +
  # Draw one point for each complete row
  geom_point(
    colour = "#2878A5",
    alpha = 0.65,
    na.rm = TRUE
  ) +
  # State both units
  labs(
    x = "Field size (acres)",
    y = "Yield (bu/ac)"
  ) +
  # Keep both horizontal and vertical guides
  theme_minimal(base_size = 11)

Three rows have missing yield, so the chart contains 57 points. The correlation is about -0.07, which agrees with the nearly flat cloud.

12.5 Show a distribution with a histogram

geom_histogram() performs the binning that the Excel workbook displayed in a formula-driven table. The settings below match the Excel boundaries: bins are 3 bu/ac wide and begin at 30.

# Map the recorded yields to the horizontal axis
ggplot(yields, aes(x = yield_bu_acre)) +
  # Match the Excel bin width and boundary
  geom_histogram(
    binwidth = 3,
    boundary = 30,
    closed = "left",
    fill = "#D8A940",
    colour = "white",
    na.rm = TRUE
  ) +
  # Show the bin boundaries
  scale_x_continuous(breaks = seq(30, 63, by = 3)) +
  # State the unit and count
  labs(
    x = "Yield (bu/ac)",
    y = "Fields"
  ) +
  # Remove unnecessary decoration
  theme_minimal(base_size = 11)

With only 57 recorded yields, the apparent shape changes noticeably when the bin width changes. The bin definition is therefore part of the analysis rather than a formatting detail.

12.6 Mapping and setting aesthetics

Put an aesthetic inside aes() when it should depend on a column. Put it outside aes() when every mark should receive the same value.

# Map colour to the region column
ggplot(
  yields,
  aes(x = acres, y = yield_bu_acre, colour = region)
) +
  geom_point(alpha = 0.65, na.rm = TRUE) +
  labs(x = "Field size (acres)", y = "Yield (bu/ac)") +
  theme_minimal(base_size = 10)

# Set one colour for all points
ggplot(yields, aes(x = acres, y = yield_bu_acre)) +
  geom_point(
    colour = "#2878A5",
    alpha = 0.65,
    na.rm = TRUE
  ) +
  labs(x = "Field size (acres)", y = "Yield (bu/ac)") +
  theme_minimal(base_size = 10)

Putting colour = "#2878A5" inside aes() would ask ggplot to treat the colour code as a data value and would create an unnecessary legend. In Excel, colouring points by region requires a separate series for each region.

12.7 Add a fitted pattern and direct label

Text can identify a small number of observations without forcing the reader to search a legend or table. The highest recorded field yield belongs to field F044.

# Find the field with the highest recorded yield
highest_field <- yields |>
  filter(!is.na(yield_bu_acre)) |>
  slice_max(yield_bu_acre, n = 1, with_ties = FALSE)

# Inspect the row that will receive a label
highest_field |>
  select(field_id, acres, yield_bu_acre)

  geom_smooth(

    hjust = 0,
    size = 3.2
  ) +
  # Leave room for the direct label
  scale_x_continuous(limits = c(0, 520)) +
  labs(
    x = "Field size (acres)",
    y = "Yield (bu/ac)"
  ) +
  theme_minimal(base_size = 11)

The fitted line is nearly flat and its interval is wide. geom_smooth() will draw a line whether or not the relationship is useful, so the points and uncertainty remain part of the interpretation.

12.8 Put explanatory text inside a chart

geom_text() attaches labels to rows in a data frame. annotate() places text at coordinates supplied in the plot code. The line chart below uses both.

# Select the lowest annual mean for a data-driven label
lowest_year <- annual_mean |>
  slice_min(mean_yield, n = 1, with_ties = FALSE) |>
  mutate(label = paste0(year, ": ", round(mean_yield, 1), " bu/ac"))

Use text for a small number of points or one necessary qualification. Labelling every point would make this ten-year series harder to read.

12.9 Divide a comparison into facets

Faceting applies the same chart definition to subsets of the data. Each panel below uses the same 3 bu/ac bins and axis limits for a different region.

# Define one histogram
ggplot(yields, aes(x = yield_bu_acre)) +
  geom_histogram(
    binwidth = 3,
    boundary = 30,
    closed = "left",
    fill = "#D8A940",
    colour = "white",
    na.rm = TRUE
  ) +
  # Repeat it for each region
  facet_wrap(~ region, nrow = 1) +
  scale_x_continuous(breaks = seq(30, 60, by = 10)) +
  labs(x = "Yield (bu/ac)", y = "Fields") +
  theme_minimal(base_size = 10)

Excel has no direct faceting feature. Separate charts can make the same comparison, but their bin definitions and axis bounds must be kept identical.

12.10 Save a plot

Assigning a plot to a name before ggsave() makes the saved object explicit and lets it be reused. Create the destination folder first.

# Create the output folder if needed
dir.create("output", showWarnings = FALSE)

# Store the finished plot in an object
regional_plot <- region_means |>
  mutate(region = fct_reorder(region, mean_yield, .desc = TRUE)) |>
  ggplot(aes(x = region, y = mean_yield)) +
  geom_col(width = 0.7, fill = "#3F6F52") +
  scale_y_continuous(
    limits = c(0, 55),
    expand = expansion(mult = c(0, 0.04))
  ) +
  labs(x = NULL, y = "Mean yield (bu/ac)") +
  theme_minimal(base_size = 11)

# Save the stated object at a reproducible size
ggsave(
  "output/region_yield_bar.png",
  plot = regional_plot,
  width = 6,
  height = 4,
  dpi = 300
)
