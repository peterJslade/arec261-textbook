Module 2 — Test Bank

NoteHow this test bank works

This bank holds 56 questions, fourteen in each section. Section 1 gives you the data inside the question; Sections 2–4 each hold two blocks of seven, one block per dataset (the datasets are described below). On the real test you receive four questions – one from each section – and you submit a single, well-commented R script: a header block at the top, a clearly labelled section for each question, and your sentence answers written as comments. The script should run from top to bottom in a project folder that has the csvs in data/. Each question is designed to take about 8–10 minutes.

Expand each Answer block to check your work. Every value has been computed from the real data; if the source file is refreshed the exact numbers may shift slightly, but the method stays the same.

The data. Two datasets, four files, all in your project’s data/ folder:

Saskatchewan RM crop yields – average yields in every Saskatchewan Rural Municipality, one row per RM-year(-crop), columns Year, RM, Crop, Yield, Unit:

  • rm_canola_yields_1990_2025.csv – the canola rows only, for Section 2: one crop, one unit, so its summary statistics mean something.
  • rm_yields_1990_2025.csv – all eight crops, for Sections 3–4. You worked with the wide version in Module 1; this is the long form, with Crop as a variable. Lentils are recorded in pounds per acre; every other crop is in bushels per acre – the Unit column says which, and several questions turn on it.

Manitoba wheat variety yields – MASC’s variety-level spring wheat yields, one row per municipality-variety-year, 2020–2025, columns Year, Municipality, Variety, Farms, Acres, Yield_bu_ac, Reported. Where too few farms grew a variety, the row is suppressed for privacy: Reported is FALSE and the numeric columns are missing.

  • mb_wheat_reported_2020_2025.csv – the reported rows only, for Section 2.
  • mb_wheat_varieties.csv – the full file, suppressed rows included, for Sections 3–4.

Grading model. 20% for script presentation – a header block, comments in the style of the module, clearly labelled question sections, and a script that runs from top to bottom in a fresh session. The remaining 80% is split evenly across the four questions, and evenly across the parts within each question. Parts are marked on follow-through: if an early part is wrong but the later parts are correctly worked from your own earlier answer, the later parts still earn full marks. Where a part asks for a sentence, write it as a comment in your script.

Vocabulary note. Everything here uses only Module 2 tools: <-, arithmetic on vectors, c(), data.frame(), $, mean, median, sd, var, min, max, range, sum, quantile (with probs), IQR, nrow, ncol, names, head, print, glimpse, summary, library(), install.packages(), read_csv with relative paths, filter (with ==, >, <, >=, &, |, !, %in%), those same comparisons applied to whole vectors (sum() of the TRUE/FALSE result counts matches), select (including - and :), rename, mutate, arrange and desc, the pipe |>, summarise, n(), group_by, and write_csv. Nothing beyond that is needed. The chapter’s summarise() examples write na.rm = TRUE inside mean() and sd(); none of the data these questions filter to has missing yields, so answers with or without it get the same numbers and the same marks.

NoteA sample test, with a full-marks answer script

A real test looks like this – one question from each section:

  1. Five canola fields yielded 52.3, 47.8, 55.1, 44.6, and 50.9 bu/ac, on 160, 320, 240, 130, and 200 acres. Create the two vectors; convert the yields to t/ha; compute the mean and sd of the yields; compute total production and the acreage-weighted average yield.
  2. Compute the mean, median, and standard deviation of canola Yield, and its 90th percentile. In a comment: the mean sits a little above the median – what does that direction of gap suggest about the shape of canola yields?
  3. Filter to the lentil rows, saving as lentils (how many rows?); add a yield_kg_ha column (multiply by 1.12), saving back to lentils; compute the mean of the new column and of the original, and check their ratio.
  4. In one pipeline, compute each RM’s mean Spring Wheat yield across all years, sorted best-first. Report the top three RMs. In a comment: what did each row of the input represent, and what does each row of the result represent?

# Section 3: converting the lentil yields
# ============================================================

# Add the converted column (1 lb/ac is about 1.12 kg/ha) and

# Means of the new and original columns

# Their ratio is 1.12, the conversion factor -- multiplying every

# ============================================================
# Section 4: best wheat-growing RMs
# ============================================================

  group_by(RM) |>                         # split the rows by RM, THEN
  summarise(mean_yield = mean(Yield)) |>  # one row per RM: its mean, THEN
  arrange(desc(mean_yield))               # best RMs on top

Question 5

A trial records, for each field: the crop grown, the seeded acres, and whether the field was irrigated.

(a) Create three vectors of length four holding made-up values for these three variables, choosing the appropriate type for each (character, numeric, logical).

(b) In a comment: which values needed quotation marks and which must not have them?

(c) Combine your three vectors into a data frame called trial and print it.
