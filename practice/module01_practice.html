Module 1 — Test Bank

Instructions

Each practice test consists of four questions, one from each type below. Download the dataset, complete the work in Excel, and check your answers by expanding the answer section below each question.

On the real test, you will receive a PDF with four questions and will submit a .xlsx workbook with your answers. You will have access to the full test bank for practice — the test draws one question randomly from each type.

Dataset

Download: sask_canola_2025.csv — 120 canola fields in Saskatchewan in 2025.

Column Description
field_id Unique field identifier (F001–F120)
region South, Central, or North
variety InVigor L345PC, DKTC 9105, PV 581 GC, or Liberty 6060
acres Field size in acres
yield_bu_ac Yield in bushels per acre
fertilizer_kg_ha Fertilizer applied in kg/ha
irrigated TRUE or FALSE
seeding_date Date the field was seeded (YYYY-MM-DD)

Import the CSV using Data → Get Data → From Text/CSV (not by double-clicking) to avoid Excel mangling any values.

Type 1: Descriptive Statistics

Using the sask_canola_2025.csv dataset, compute the following summary statistics for the yield_bu_ac column. Place each answer in a clearly labelled cell, using an Excel formula (not a hard-coded value).

(a) Compute the mean yield across all 120 fields.

(b) Compute the median yield.

(c) Compute the sample standard deviation of yield.

(d) Compute the sample variance of yield.

(e) Compute the first quartile (Q1) and third quartile (Q3) of yield.

(f) Compute the interquartile range (IQR).

(g) Compute the 90th percentile of yield. Write one sentence explaining what this number means in plain language.

(h) Is the mean or the median higher? What does this tell you about the shape of the distribution?

Answers
Part Value Formula
(a) Mean 45.65 bu/ac =AVERAGE(E2:E121)
(b) Median 46.25 bu/ac =MEDIAN(E2:E121)
(c) Std dev 5.80 bu/ac =STDEV.S(E2:E121)
(d) Variance 33.66 (bu/ac)2 =VAR.S(E2:E121)
(e) Q1 42.27 bu/ac =QUARTILE.INC(E2:E121, 1)
(e) Q3 49.42 bu/ac =QUARTILE.INC(E2:E121, 3)
(f) IQR 7.15 bu/ac =QUARTILE.INC(E2:E121,3) - QUARTILE.INC(E2:E121,1)
(g) P90 52.50 bu/ac =PERCENTILE.INC(E2:E121, 0.9)

Part (g) interpretation: 90% of fields in this dataset yielded 52.50 bu/ac or less. Equivalently, only 10% of fields exceeded this yield.

Part (h): The median (46.25) is higher than the mean (45.65), which indicates a slight left (negative) skew — a small number of low-yielding fields pull the mean downward. This is common in yield data, where a few fields may fail or underperform badly while most cluster in a narrower range.

Common mistakes:

  • Using STDEV.P instead of STDEV.S. Use .S for samples.
  • Forgetting that PERCENTILE.INC takes a decimal (0.9), not a percentage (90).
  • Hard-coding a number instead of using a formula — the grader checks for formulas.

Type 2: Conditional Functions and Lookups

Using the same dataset, answer the following. Each answer should use an Excel formula.

(a) How many fields have a yield strictly greater than 50 bu/ac?

(b) What is the average yield in the South region? In the Central region? In the North region?

(c) What is the total production (in bushels) across all 120 fields? (Hint: production = yield × acres.)

(d) What is the total production in the South region only?

(e) How many fields are irrigated AND in the Central region?

(f) What variety was planted in field F050? What about F100? (Use a lookup function — do not scroll through the data manually.)

(g) Write a formula that classifies each field’s yield as “Low” (below 40), “Medium” (40 to 50), or “High” (above 50).

Answers
Part Value Formula
(a) Count > 50 26 =COUNTIF(E2:E121, ">50")
(b) Avg South 43.39 bu/ac =AVERAGEIF(B2:B121, "South", E2:E121)
(b) Avg Central 47.54 bu/ac =AVERAGEIF(B2:B121, "Central", E2:E121)
(b) Avg North 46.41 bu/ac =AVERAGEIF(B2:B121, "North", E2:E121)
(c) Total production 1,533,356.4 bu =SUMPRODUCT(D2:D121, E2:E121)
(d) South production 574,485.2 bu =SUMPRODUCT((B2:B121="South")*D2:D121*E2:E121)
(e) Irrigated & Central varies =COUNTIFS(G2:G121, "TRUE", B2:B121, "Central")
(f) F050 variety InVigor L345PC =XLOOKUP("F050", A2:A121, C2:C121)
(f) F100 variety DKTC 9105 =XLOOKUP("F100", A2:A121, C2:C121)

Part (g): In a new column, enter in the first data row:

=IFS(E2<40, "Low", E2<=50, "Medium", TRUE, "High")

or equivalently:

=IF(E2<40, "Low", IF(E2<=50, "Medium", "High"))

Copy this formula down to all 120 rows. Both approaches are acceptable.

Notes:

  • For part (d), SUMPRODUCT with a boolean condition is the most compact approach. Alternatively, create a helper column with =D2*E2, then =SUMIF(B2:B121, "South", helper_range).
  • For part (f), XLOOKUP is preferred in modern Excel. VLOOKUP works too: =VLOOKUP("F050", A2:C121, 3, FALSE). Always use FALSE for exact match.
  • For part (e), COUNTIFS (plural) handles multiple conditions. Each condition is a separate pair of arguments.

Type 4: Charts

Create the following charts on a new sheet in your workbook. Each chart should have a descriptive title, labelled axes, and be formatted so that someone unfamiliar with the data can understand what it shows.

(a) Create a histogram of yield_bu_ac for all 120 fields. Use approximately 10–15 bins.

Answer the following based on your histogram:

  • Is the distribution roughly symmetric, left-skewed, or right-skewed?
  • Are there any obvious outliers?
  • What is the approximate centre of the distribution?

(b) Create a box-and-whisker plot comparing yield_bu_ac across the three regions (South, Central, North).

Answer the following based on your box plot:

  • Which region has the highest median yield?
  • Which region has the most variability in yield (widest box)?
  • Are there any outliers flagged in any region?
Answers

Part (a) — Histogram:

How to create: Select the yield_bu_ac column → Insert → Statistical Chart → Histogram. Right-click the horizontal axis → Format Axis → set bin width to about 2.5–3.0 bu/ac (to get 10–12 bins across the range of ~29 to ~58).

Formatting: Add a title like “Distribution of Canola Yields, Saskatchewan 2025”. Label x-axis as “Yield (bu/ac)” and y-axis as “Number of Fields”.

Expected interpretation:

  • The distribution is slightly left-skewed — there is a longer tail on the low end (a few fields below 35 bu/ac) while the upper end tapers off more quickly.
  • There may be one or two potential outliers at the low end (fields around 29 bu/ac).
  • The centre is around 45–47 bu/ac, consistent with the mean (45.65) and median (46.25).

Part (b) — Box plot:

How to create: Select the region and yield_bu_ac columns → Insert → Statistical Chart → Box and Whisker.

Formatting: Add a title like “Yield Distribution by Region, Saskatchewan 2025”. Label x-axis as “Region” and y-axis as “Yield (bu/ac)”.

Expected interpretation:

South Central North
Q1 38.8 43.5 43.3
Median 44.6 47.3 46.5
Q3 48.4 51.0 50.7
Min 28.9 37.2 36.1
Max 54.5 57.8 53.3
  • Central has the highest median yield (47.3 bu/ac).
  • South has the widest box (IQR ≈ 9.6), indicating the most variability. Central and North have similar spreads (IQR ≈ 7.5).
  • There may be outliers flagged in the South region at the low end (fields well below Q1 − 1.5×IQR).

Common mistakes:

  • Not labelling axes. Unlabelled charts are unacceptable — always include axis labels and a title.
  • Using too few or too many histogram bins. Fewer than 6 bins hides the shape; more than 20 shows noise. Adjust and pick the one that makes the shape clearest.
  • Forgetting to specify that the box plot should compare regions — if you just select the yield column without the region column, you get one box instead of three.
